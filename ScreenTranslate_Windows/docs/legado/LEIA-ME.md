# Documentos arquivados (Fase 1)

Cópias **sem alterações** do README e do guia rápido originais do protótipo, guardadas por
rastreabilidade (decisão L04 em `docs/LIMPEZA_PROJETO.md`). Os arquivos são idênticos, byte a byte,
aos do ZIP original da Fase 0; um teste automatizado confere isso.

Eles **não descrevem o comportamento real**: trazem a narrativa de uma análise de APK que não acompanha
o projeto, afirmações absolutas sem teste, instruções que divergem entre si (como encerrar, versão do
Python, pastas de modelos, pares de idioma) e uma seção de empacotamento nunca verificada.

Use o `README.md` e o `GUIA_RAPIDO_WINDOWS.md` da raiz do projeto.
